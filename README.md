## Tools Used
- SQL
- Python
- Power BI
- Excel

 ## Key objectives
  - Analyze loan applicant profiles
  - Identify factors affecting loan approval
  - Evaluate applicant risk levels
  - Support data driven lending decisions
 
## Recommendations
- Strengthen screening for high risk applicants
- Use credit history as a primary approval factor
- Implement risk based loan pricing
